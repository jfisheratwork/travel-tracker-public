Help & Information

Welcome to Traveled Roads Tracker! This application helps you explore, log, and visualize visited National Parks, States & Provinces, and Road Trips across the United States and Canada with interactive mapping, completion statistics, and trip memory logs.

❤️ Open Source Attributions & Credits

This project proudly uses and builds upon the following open-source software, cartographic libraries, and public data APIs:

  • •
    Angular: Standalone component application framework, reactivity primitives, and tooling (angular.dev).
  • •
    Leaflet: Open-source JavaScript interactive mapping library powering map zoom, layers, panes, and marker management (leafletjs.com).
  • •
    OpenStreetMap: Collaborative free and open world geographic data and cartography contributors (openstreetmap.org).
  • •
    CARTO: Basemap styling and high-performance tile rendering with CARTO Voyager raster tiles (carto.com).
  • •
    OSRM (Open Source Routing Machine): High-performance C++ routing engine for road network pathfinding and turn-by-turn route geometry (project-osrm.org).
  • •
    Nominatim: OpenStreetMap search and reverse geocoding engine powering location lookups (nominatim.org).
  • •
    Tailwind CSS: Utility-first CSS framework for modern styling, responsive layouts, and animations (tailwindcss.com).
  • •
    Vitest: Vite-native high performance test runner for unit testing (vitest.dev).
  • •
    ESLint & Prettier: Code analysis, formatting, and linting quality tools (eslint.org, prettier.io).
  • •
    GeoJSON & Natural Earth: Public domain cartographic boundary datasets for US States, Canadian Provinces, and National Parks.
